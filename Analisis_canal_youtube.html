1. ¿Qué vamos a construir?

Vas a construir un sistema profesional de análisis de YouTube que hace tres cosas:

ProductoQué esPara quién
CSVLista de los últimos videos del canal con todos sus datosIntermedio (lo leen los scripts)
Excel (.xlsx)Análisis completo con 10 hojas, gráficas y análisis de miniaturasTú, para trabajar
PDF de reporteInforme profesional con conclusiones, recomendaciones y miniaturasTu cliente final
💡 Ejemplo: analizamos el canal Eloisa Wolf (@EloisaWolf). El mismo sistema funciona para cualquier canal cambiando una sola línea.

4. Obtener la API Key de YouTube (gratis)

NAVEGADOR La API Key es una clave que te da Google para leer datos de YouTube. Es gratis y tarda 2 minutos.

1
Entra a Google Cloud Console
Ve a console.cloud.google.com y accede con tu cuenta de Google.
2
Crea un proyecto
Arriba a la izquierda → selector de proyectos → "Nuevo proyecto". Ponle un nombre como "Analisis YouTube".
3
Habilita la YouTube Data API v3
En el buscador, escribe "YouTube Data API v3". Entra y haz clic en "Habilitar".
4
Crea la API Key
Menú lateral → "Credenciales" → "+ Crear credenciales" → "Clave de API". Google te dará una clave como AIzaSyB....
5
Cópiala y guárdala
Pégala en un bloc de notas. La usarás en el paso 5.
💡 Cuota gratuita: 10.000 unidades por día. Analizar un canal de 30 videos consume ~150 unidades. Puedes analizar ~60 canales al día gratis.
❌ Nunca compartas tu API Key en capturas, videos o GitHub público. Si se filtra, cualquiera puede gastar tu cuota diaria.

from googleapiclient.discovery import build import csv # --- CONFIGURA AQUI --- API_KEY = "PEGA_AQUI_TU_API_KEY" CHANNEL_HANDLE = "EloisaWolf" MAX_VIDEOS = 30 # ----------------------- youtube = build("youtube", "v3", developerKey=API_KEY) busqueda = youtube.search().list( part="snippet", q=CHANNEL_HANDLE, type="channel", maxResults=1 ).execute() if not busqueda["items"]: print("No se encontro el canal. Revisa el handle.") raise SystemExit channel_id = busqueda["items"][0]["snippet"]["channelId"] channel_title = busqueda["items"][0]["snippet"]["title"] print(f"Canal encontrado: {channel_title}") info_canal = youtube.channels().list( part="contentDetails,statistics", id=channel_id ).execute() uploads = info_canal["items"][0]["contentDetails"]["relatedPlaylists"]["uploads"] subs = info_canal["items"][0]["statistics"].get("subscriberCount", "0") print(f"Suscriptores: {subs}") lista_videos = youtube.playlistItems().list( part="snippet", playlistId=uploads, maxResults=MAX_VIDEOS ).execute() video_ids = [it["snippet"]["resourceId"]["videoId"] for it in lista_videos["items"]] stats = youtube.videos().list( part="statistics,contentDetails,snippet", id=",".join(video_ids) ).execute() filas = [] for v in stats["items"]: sn, st = v["snippet"], v["statistics"] filas.append({ "canal": channel_title, "handle": CHANNEL_HANDLE, "suscriptores_canal": subs, "titulo": sn["title"], "publicado": sn["publishedAt"], "vistas": st.get("viewCount", 0), "likes": st.get("likeCount", 0), "comentarios": st.get("commentCount", 0), "duracion": v["contentDetails"]["duration"], "url": f"https://youtube.com/watch?v={v['id']}", "miniatura": sn["thumbnails"]["high"]["url"], }) filas.sort(key=lambda x: int(x["vistas"]), reverse=True) nombre_csv = f"{CHANNEL_HANDLE}.csv" with open(nombre_csv, "w", newline="", encoding="utf-8") as f: w = csv.DictWriter(f, fieldnames=filas[0].keys()) w.writeheader() w.writerows(filas) print(f"Listo: {len(filas)} videos guardados en {nombre_csv}")

10. Cómo interpretar los resultados

📊 Mediana vs promedio

Siempre mira la mediana primero. El promedio se distorsiona con videos virales. Si el promedio es muy superior a la mediana, unos pocos videos hacen todo el trabajo.

🎯 Vistas por 1000 suscriptores

RangoSignificadoAcción
+100🟢 Excelente alcanceMantener estrategia
50-100🟡 SaludableOptimizar títulos y miniaturas
20-50🟠 Necesita mejorarRevisar temas y formatos
-20🔴 Problema serioCambio de estrategia urgente

🎨 Análisis de miniaturas

El script clasifica colores dominantes de cada miniatura. Si los videos más exitosos comparten un color (por ejemplo, Rojo/Calido), esa es una pista para tus próximas miniaturas.

⏱️ Duración

Compara la mediana de vistas entre categorías. La categoría con la mediana más alta es tu duración ganadora.
